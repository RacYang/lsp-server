# 弃用功能

## When to use

当需要停止推荐某个协议字段、配置项、玩法能力、命令或部署路径时使用。

## Inputs

- 被弃用对象。
- 兼容期与迁移目标。
- 是否需要 ADR。

## Steps

1. 判断弃用是否影响稳定契约；影响时先新增 ADR。
2. 在文档中标明替代方案与迁移窗口。
3. 保留必要兼容路径，避免破坏已发布行为。
4. 到退役阶段再使用对应 retire 命令删除资产。

## Verify

- 运行相关测试。
- 文档变更运行 `make verify-meta`。
