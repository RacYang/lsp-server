# 弃用功能

## When to use

当需要停止推荐某个协议字段、配置项、玩法能力、命令或部署路径时使用。

## Inputs

- 被弃用对象。
- 兼容期与迁移目标。
- 是否需要 ADR。

## Steps

1. **输出全量影响面**：列出所有引用方（代码、文档、ADR、config）；确认无用户可见不兼容影响；声明迁移窗口（ADR-0049）。
2. 判断弃用是否影响稳定契约；影响时先新增 ADR。
3. 在文档中标明替代方案与迁移窗口。
4. 保留必要兼容路径，避免破坏已发布行为。
5. 到退役阶段再使用对应 retire 命令删除资产。

## Verify

- 运行 `python3 scripts/verify-doc-links.py`（弃用注记引用路径不悬空）。
- 运行 `make verify-fast`（编译 + 单元测试通过）。
- 确认弃用目标不再出现在 `make verify` 的报错输出中。
- 若涉及 proto：运行 `buf breaking`。
