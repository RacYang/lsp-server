# ADR-0048 Agent 优先的治理文档格式

## 决策

- 治理资产（rules、commands、templates、ADR、CLAUDE.md）以 agent 解析效率为唯一优化目标。
- 格式规范：列表/表格/代码块；禁止解释性散文和背景叙述段落。
- rule 正文上限 10 行；超出须拆分为独立 rule。
- ADR 正文固定结构：`## 决策`（bullet）+ `## 后果`（bullet）；`## 背景` 最多 5 行，仅用于无法自解释的约束前提。
- commands 三节固定：`## Inputs`、`## Steps`（编号列表）、`## Verify`。
- 禁止跨文档内容重复；交叉引用用路径表达。

## 后果

- 现有 ADR 的 `## 背景` 节不强制回溯改写；新增 ADR 必须遵守。
- rule 超 10 行的现存规则下次修改时同步拆分，不强制立即回溯。
- 评审标准：PR 中新增治理文档若有散文段落，需要显式说明为何无法结构化。
