# lsp-cli 玩法说明

这份文档面向最终玩家，告诉你怎么把 `lsp-cli` 打开、登入大厅、上桌打牌。
更偏开发的内容（命令行参数、依赖边界、测试方法等）在同目录的 `README.md`。

## 1. 启动

唯一启动说明见 [前端启动方式](../../docs/FRONTEND.md)。这里不复制启动命令，避免多份说明漂移。

第一次启动会问你昵称：

```text
请输入昵称 > 小明
```

输入完按回车，客户端就会连接到默认服务器。昵称、服务器和登录令牌会保存到
`~/.lsp/config.toml`（Windows 在 `%USERPROFILE%\.lsp\config.toml`），下次启动直接续接。

## 2. 大厅

```text
lsp · 大厅 · 小明                                      ● 23ms

        ┌ 快速开始 ┐   ┌ 创建房间 ┐   ┌ 加入房间码 ┐   ┌ 公开房间 ┐
        │ 自动补齐 │   │ 选择玩法 │   │ 好友邀请   │   │ 等候房   │
        │ Enter    │   │ Enter    │   │ Enter      │   │ Enter    │

←→/↑↓ 选择    Enter 确认    ? 帮助    q 退出
```

- **快速开始**：自动找一个空座；如果没有就帮你开一桌新公开房并入座。
- **创建房间**：先选玩法，再选公开性，最后确认房间名。私密房会显示房间码，分享给好友即可。
- **加入房间码**：直接粘贴 / 输入房间码。
- **公开房间**：查看公开等候房并选择加入。
- **退出**：回到桌面。

如果服务端把你踢出（违规、断线超时等），lobby 会立刻收到一条红字提示。

## 3. 牌桌界面

进入房间后客户端会自动准备，然后整个终端切换到全屏牌桌，画面大概长这样：

牌桌框就是麻将桌面。自己永远在底部；下家在左、对家在上、上家在右。
自己的手牌用两行中文显示，其他三家显示“牌”作为牌背，中央显示当前阶段和倒计时。

牌堆中央会根据当前进度显示：

- "等待玩家就位"（坐位还没坐满）。
- "已自动准备,等待其他玩家就位"（你已经准备，等待其他玩家）。
- "等待 alice 出牌"（别人在思考）。
- "该你打牌"（轮到你）。

## 4. 出牌与摸牌

### 普通出牌

1. 用 `←` / `→` 在底部的手牌上左右移动光标，光标所在的牌会"凸起"突出显示。
2. 按 `Enter` 确认打出。
3. 出牌发到服务端等待确认，期间这张牌会变灰，避免你重复操作。

### 换三张

1. 把光标移到要换出的牌上，按 `Space` 标记，再次 `Space` 取消标记。
2. 顶部会显示 `已选 N/3`。选满 3 张后按 `Enter` 提交。

### 定缺

换三张结束后会进入定缺阶段，按 `m / p / s` 分别选择缺万、缺筒、缺条。

## 5. 碰、杠、胡的弹窗

当别家打出的牌可以被你碰、杠或胡时，屏幕中央会弹出一段文字决策：

```text
   ┌────────────────────────────────────┐
   │          alice 打出 七筒           │
   │                                    │
   │       ▶ 胡：就这张牌和牌          │
   │         碰：拿下这张牌            │
   │         过：放过这次机会          │
   │                                    │
   │  还剩 4.2 秒  ███████░░░░░░░░░    │
   │       现在：←→ 选择　Enter 确认   │
   └────────────────────────────────────┘
```

- 用 `←` / `→` 切换决定，也可以直接按 `h / g / p / n` 选择胡 / 杠 / 碰 / 过。
- 按 `Enter` 确认当前决定。
- 进度条走完（客户端默认约 4.5 秒）会自动按"过"。服务端会给每个被接力到的候选完整 5 秒窗口。

自摸时会显示"你摸到某张牌"，决定会变成"胡：宣告自摸 / 不胡：留在手里继续打"。主动不胡后，摸到的牌会进手，你可以自己选择接下来打哪张。

## 6. 浮窗与菜单

- `i`：调出当前房间信息（房号、规则、人数、私密标志）。
- `Tab`：调出玩家列表详情。
- `Esc`：调出局内菜单，可以继续游戏或返回大厅；返回大厅会先通知服务端离桌。
- 弹窗都用同一套键位：`←→` 选项 / `Enter` 确认 / `Esc` 关闭。

## 7. 结算

一局结束时会弹出结算浮窗，先揭晓结果和你的得失，再展开胡家、番种和每家分数：

```text
   ╔═ 本局结算 ═════════════════════════╗
   ║              胡了，你赢了          ║
   ║              你本局 +24            ║
   ║       胡家：你  8 番（清一色、门清）║
   ║       番种：清一色 +6、门清 +2     ║
   ║              alice：-8             ║
   ║              bob：-8               ║
   ║              carl：-8              ║
   ╚════════════════════════════════════╝
```

结算同时会在你的命令行里输出一段文本摘要，方便回看：

```text
== 本局摘要 ==
房间: room_xxxx  规则: 川麻血战
胜者: 你 (清一色 + 门清, 8 番)
你: +24   alice: -8   bob: -8   carl: -8
```

按 `r` 再开一桌，按 `l` 离桌，按 `Enter` 停留查看结算。

## 8. 网络异常

牌桌阶段如果断线，屏幕中央会盖一层"网络异常,重连中..."的浮窗，不打断牌局画面。
30 秒还没恢复时浮窗会增加一个"返回大厅"按钮，按 `Enter` 主动放弃这桌。

## 9. 终端建议

- 至少 100 列 × 30 行。窗口太小会被拒绝进入牌桌，放大窗口后再试。
- 中文字体推荐：Sarasa Mono、JetBrains Mono CN、Noto Sans Mono CJK 等等宽 CJK 字体。
- 客户端固定使用纯中文牌面和 Unicode 框线，不再提供 ASCII 或 emoji 主题切换。

## 10. 常见问题

| 问题 | 处理 |
| --- | --- |
| 启动时卡在"登录中..." | 检查网络或服务器地址，必要时删除 `~/.lsp/config.toml` 重新登录 |
| 牌打错了 | 出牌前是两步式：选 + Enter，没确认前都可以左右移光标改主意 |
| 弹窗按 Enter 没反应 | 可能是因为本应是 `←→` 切换的多按钮场景，先用方向键选中再 Enter |
| 牌画错位 | 换一款 CJK 等宽字体，并确认终端宽度至少 100 列 |
| 想换服务器 | 启动时加 `--ws wss://你的服务器/ws`，或编辑 `~/.lsp/config.toml` 的 `server_url` |
