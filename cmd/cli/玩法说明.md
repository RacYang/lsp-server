# lsp-cli 玩法说明

这份文档面向最终玩家，告诉你怎么把 `lsp-cli` 打开、登入大厅、上桌打牌。
更偏开发的内容（命令行参数、依赖边界、测试方法等）在同目录的 `README.md`。

## 1. 启动

直接运行下载到的可执行文件：

- macOS / Linux：双击 `scripts/lsp-cli.sh`，或在终端里执行 `./scripts/lsp-cli.sh`。
- Windows：双击 `scripts/lsp-cli.ps1` 或 `lsp-cli_windows_amd64.exe`。

第一次启动会问你昵称：

```
请输入昵称 > 小明
```

输入完按回车，客户端就会连接到默认服务器。昵称、服务器和登录令牌会保存到
`~/.lsp/config.toml`（Windows 在 `%USERPROFILE%\.lsp\config.toml`），下次启动直接续接。

## 2. 大厅菜单

```
请选择:
  1) 快速开始
  2) 查看公开房间
  3) 创建房间
  4) 输入房间码加入
  5) 修改昵称
  q) 退出
> 1
```

输入数字回车即可。

- **快速开始**：自动找一个空座；如果没有就帮你开一桌新公开房并入座。
- **查看公开房间**：列出所有公开房，按编号选房或按 `0` 返回。
- **创建房间**：依次问规则、房间名、是否私密。私密房会打印 6 位房间码，
  分享给好友让他们用第 4 项加入。
- **输入房间码加入**：直接粘贴 / 输入房间码即可。
- **修改昵称**：换个昵称，下次重连生效。
- **退出**：回到桌面。

如果服务端把你踢出（违规、断线超时等），lobby 会立刻收到一条红字提示。

## 3. 牌桌界面

- "已自动准备,等待其他玩家就位"（你已经准备，等待其他玩家）。
- "等待 alice 出牌"（别人在思考）。
- "该你打牌"（轮到你）。

## 4. 出牌与摸牌

**普通出牌（最常用）**

1. 用 `←` / `→` 在底部的手牌上左右移动光标，光标所在的牌会"凸起"突出显示。
2. 按 `Enter` 确认打出。
3. 出牌发到服务端等待确认，期间这张牌会变灰，避免你重复操作。

**换三张（开局调整阶段）**

1. 把光标移到要换出的牌上，按 `Space` 标记，再次 `Space` 取消标记。
2. 顶部会显示 `已选 N/3`。选满 3 张后按 `Enter` 提交。

**定缺**

换三张结束后会进入定缺阶段，按 `m / p / s` 分别选择缺万、缺筒、缺条。

## 5. 碰、杠、胡的弹窗

当上家打出的牌可以被你碰、杠或胡时，屏幕中央会弹出居中浮窗：

```
   ┌───────────────────────────┐
   │ alice 打出 [七 筒]        │
   │                           │
   │   [ 碰 ]    [ 胡 ]    [ 过 ]
   │                           │
   │ ████████░░░░░░░░░░ 4.2s   │
   └───────────────────────────┘
```

- 用 `←` / `→` 切换按钮，也可以直接按 `h / g / p / n` 选择胡 / 杠 / 碰 / 过。
- 按 `Enter` 确认当前高亮按钮。
- 进度条走完（客户端默认约 4.5 秒）会自动按"过"。服务端会给每个被接力到的候选完整 5 秒窗口。

自摸时浮窗标题会改成"自摸"，按钮直接显示"胡 / 不胡"。主动不胡后，摸到的牌会进手，你可以自己选择接下来打哪张。

## 6. 浮窗与菜单

- `i`：调出当前房间信息（房号、规则、人数、私密标志）。
- `Tab`：调出玩家列表详情。
- `Esc`：调出局内菜单，可以在这里切换 `unicode / ascii` 牌面主题，或直接返回大厅；返回大厅会先通知服务端离桌。
- 弹窗都用同一套键位：`←→` 选项 / `Enter` 确认 / `Esc` 关闭。

## 7. 结算

一局结束时会弹出结算浮窗，逐行揭晓每个玩家的得失：

```
            === 结算（你赢了）===
   alice    -8 番
 > 我        +24 番   （胡）
   bob      -8 番
   carl     -8 番
            按 q 离桌
```

结算同时会在你的命令行里输出一段文本摘要，方便回看：

```
[结算] 房间=room_xxxx  结果=你赢了  总番=24
  alice    -8
> 我        +24  ← 自己
  bob      -8
  carl     -8
```

按 `Enter` 或 `q` 都会离桌回到大厅。

## 8. 网络异常

牌桌阶段如果断线，屏幕中央会盖一层"网络异常,重连中..."的浮窗，不打断牌局画面。
30 秒还没恢复时浮窗会增加一个"返回大厅"按钮，按 `Enter` 主动放弃这桌。

## 9. 终端建议

- 至少 64 列 × 20 行。窗口太小会被拒绝进入牌桌，放大窗口后再试。
- 中文字体推荐：Sarasa Mono、JetBrains Mono CN、Noto Sans Mono CJK 等等宽 CJK 字体。
- 字体不支持 CJK 双宽字符时在局内菜单 `Esc → 牌面主题` 里切换为 `ASCII`：

  ```
  +--++--++--+
  |m1||p3||s9|
  |  ||  ||  |
  +--++--++--+
  ```

## 10. 常见问题

| 问题 | 处理 |
| --- | --- |
| 启动时卡在"登录中..." | 检查网络或服务器地址，必要时删除 `~/.lsp/config.toml` 重新登录 |
| 牌打错了 | 出牌前是两步式：选 + Enter，没确认前都可以左右移光标改主意 |
| 弹窗按 Enter 没反应 | 可能是因为本应是 `←→` 切换的多按钮场景，先用方向键选中再 Enter |
| 牌画错位 | 切换到 `ASCII` 主题，或换一款 CJK 等宽字体 |
| 想换服务器 | 启动时加 `--ws wss://你的服务器/ws`，或编辑 `~/.lsp/config.toml` 的 `server_url` |
