# Agent 模板索引

本目录保存代码骨架、注释样板、文件头与文档骨架。新增模板请使用 `.cursor/skills/add-template/SKILL.md`，并为每个模板目录提供 `manifest.yaml`。

## 分类

- `code/`：Go 包、handler、service、repository、actor、CLI 与 proto 骨架。
- `comment/`：包、导出类型、导出函数与 ADR 引用注释样板。
- `header/`：生成物、Shell、Python 等文件头样板。
- `doc/`：ADR、rule、skill、runbook 与 template 文档骨架。
